File Saya

Akses folder file pribadi setiap guru di Google Drive. Pilih nama Anda untuk melihat folder dan status file Anda sendiri. Halaman ini terpisah dari halaman laporan folder.

Bagaimana cara kerjanya?

File asli guru tetap tersimpan di Google Drive, bukan di halaman ini. Yang mengatur siapa dapat membuka file adalah pengaturan berbagi (sharing) di Drive: folder atas nama seorang guru hanya dibagikan kepada guru itu sendiri dan Tim Kurikulum. Karena itu, guru lain yang mencoba membuka folder tersebut akan ditolak oleh Drive dan diminta meminta akses — file guru lain tidak dapat dilihat dari namanya sendiri.

Catatan: halaman laporan ini dapat dibaca semua guru, tetapi tombol folder di bawah hanya membuka file apabila akun Google Anda memang sudah diberi akses ke folder tersebut oleh Tim Kurikulum.

Panduan Tim Kurikulum — Mengatur Folder per Guru di Drive

Langkah ini dilakukan satu kali untuk setiap folder guru, supaya benar-benar hanya guru yang bersangkutan yang dapat membukanya.

  1. Buka folder arsip di Google Drive (misalnya 16. Jurnal Mengajar), lalu masuk ke subfolder atas nama guru yang akan diatur.
  2. Klik kanan nama subfolder tersebut, pilih Bagikan → Bagikan.
  3. Pada bagian Akses umum, pilih Dibatasi — jangan pilih “Siapa saja yang memiliki link”, karena pilihan itu membuat siapa pun yang memegang link dapat membuka foldernya.
  4. Tambahkan hanya alamat email guru yang bersangkutan, ditambah email Tim Kurikulum dan Kepala Sekolah bila diperlukan.
  5. Atur peran guru tersebut: Pelihat (Viewer) bila guru hanya perlu melihat file, atau Editor bila guru perlu mengunggah file ke foldernya sendiri. Pada pengaturan lanjutan, matikan pilihan agar editor dapat mengubah izin berbagi, supaya guru tidak dapat membagikan foldernya ke orang lain.
  6. Klik Salin link pada folder itu, lalu kirimkan link tersebut secara pribadi kepada guru yang bersangkutan. Jangan mengumumkan satu link untuk semua guru.
  7. Ulangi langkah yang sama untuk setiap guru dan setiap folder arsip. Periksa kembali daftar orang yang memiliki akses secara berkala, dan cabut akses yang sudah tidak diperlukan.
  8. Guru membuka file-nya dari link pribadi tersebut, atau dari menu “Dibagikan kepada saya” di Google Drive miliknya. Apabila Drive menampilkan pesan “Minta akses”, berarti folder itu belum dibagikan ke akun guru tersebut — hubungi Tim Kurikulum.
